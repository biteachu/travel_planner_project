# 적용 방향

2026-11-23 사용자가 공개 비교 페이지의 A 시안을 선택하고 B/C의 적절한 혼합과 창의적 조정을 위임했다. 무작위 콘셉트 선택은 사용하지 않았다. 아래 내용은 사용자 선택과 현재 구현을 기록하며, 사전에 실행하지 않은 절차나 승인을 만들지 않는다.

## Direction contract

THESIS: 여행을 한 권으로 읽고 가져가는 제품. 파란 책 표지와 선명한 한국어 제목으로 사용자가 선택한 방향을 유지한다.

OWN-WORLD: 흰색 #ffffff, 파랑 #0754f8, 잉크 #172228, 라임 #ceff64. Pretendard. 읽는 본문은 흰 바탕, 탐색·진행 도구는 반투명 유리, 다중 거점 표지는 잉크/라임.

STORY: 예시를 펼치고, 취향을 입력하고, 자신의 키로 생성·검토한 뒤 HTML로 가져간다. 설치 안내는 홈 화면 아이콘으로 다시 방문하는 방법을 제공한다.

FIRST VIEWPORT: 데스크톱은 왼쪽 큰 제목·주 행동, 오른쪽 파란 책. 모바일은 제목·행동·책 순서. 생성·편집은 기존 표준 컨트롤과 흐름을 유지한다. 가이드북은 표지·목차·날짜별 본문 순서.

FORM: 사용자가 A를 직접 선택한 코드 기반 시안. 예시 비교 페이지와 보존한 화면이 기준이며 랜덤 seed나 외부 QUALITY BAR 카드가 있는 것으로 표시하지 않는다. 첫 화면은 Persuade, 입력·편집은 Operate, 가이드북은 Read.

FINISH: 실제 데스크톱·모바일 화면과 동작을 검증하고 디자인 체계를 기록한다. 사용자 키의 실제 생성, 실제 iPhone 설치 완료를 모의 검사로 대체해 주장하지 않는다.
