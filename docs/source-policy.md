# 조사 자료와 HTML 내보내기 검토

확인일: 2026-11-18. 이 문서는 구현 결정을 위한 공식 문서 대조 기록이며 법률 자문이나 서비스 제공사의 허가를 대신하지 않는다.

## 확인 결과

- Google Maps Grounding 문서는 출처 이름·링크를 해당 내용 바로 뒤에 표시하고, `Google Maps` 명칭을 번역하거나 줄바꿈하지 않도록 요구한다. [표시 요건](https://aistudio.google.com/docs/maps-grounding#service-usage-requirements)
- Gemini 추가 약관의 Maps 절에는 결과 수정·혼합, 저장과 지도 데이터 내보내기 제한이 있다. 현재의 장기 보관·편집·HTML 출력 구조에 단순한 출처 표시만 추가하여 적합하다고 판단할 수 없다. [Maps 약관](https://aistudio.google.com/docs/terms#grounding-with-google-maps)
- 검색 Grounding에도 검색 제안 동반 표시, 저장 및 결과 재사용 조건이 있다. 사용자 개별 복사 예외가 존재하더라도 자동 수집·DB 저장·다단계 재작성 전체를 허용한다고 해석하지 않는다. 현재 구현은 제공된 검색 제안 메타데이터를 표시하지 않는다. [검색 약관](https://aistudio.google.com/docs/terms#grounding-with-google-search)

## 제품 요구와의 관계

제품의 핵심 요구는 사용자 취향에 맞는 여행 계획을 편집하고, 단일 HTML로 보관하며, 선택적으로 계정에 저장하는 것이다. 이를 포기하는 대신 조사 자료의 이용 가능 범위를 먼저 확정해야 한다.

확정 방향은 Gemini를 계획·검토에 유지하고, 가이드북의 사실 근거는 저장·변형·재배포가 허용된 공개 자료로 분리하는 것이다. 사용자 선택에 따라 HTML 가이드북을 유지하고 공개 자료로 조사 경로를 전환한다. 특정 제공사의 API 연결과 데이터 품질 검증은 아직 완료하지 않았다. Google Maps를 여는 일반 검색 링크와 Maps Grounding에서 받은 데이터를 구분한다. 일반 지도 링크를 제공한다고 지도 데이터 저장 권한이 생기는 것은 아니다.

## 구현 현황과 다음 확인

현재 코드에서 Maps 조사 → Search 대체 호출을 제거하고 Wikivoyage 본문 조회로 교체했다. Gemini는 문서명 선택과 이후 계획·검토를 담당한다. 원문·버전·기여자 이력 링크, CC BY-SA 4.0과 번역·재구성 표시를 저장 및 HTML 출력에 포함한다. 자료가 없는 문서는 출처로 등록하지 않는다. 사진은 가져오지 않는다.

실제 API에서 Hiroshima·Istanbul·Cappadocia 세 문서의 본문과 버전을 읽는 테스트를 통과했다. 여러 문서를 묶은 요청에서 일부 본문만 반환되는 경우를 확인하여 문서별 순차 조회로 변경했다. 요청마다 시간·응답 크기 제한을 적용하고 서비스 오류를 빈 자료로 숨기지 않는다. 이 검증은 Gemini의 문서명 선택 정확성이나 개별 업체의 현재 영업 확인을 대신하지 않는다.

PowerShell에서 `$env:RUN_LIVE_RESEARCH='1'; npm run test -- tests/open-research.test.ts`로 실제 API 검증을 실행할 수 있다. 일반 테스트에서는 네트워크 검증을 건너뛴다. 외부 API의 자료·응답 속도에 따라 결과가 달라질 수 있다.

다음 작업에서는 후보 자료마다 다음을 확인한다.

1. 라이선스, 출처·저작자 표시, 변경 표시, 동일조건 배포 여부.
2. HTML·JSON·DB·진행 체크포인트에 저장 가능한 필드와 보관 기간.
3. API 호출 한도·사용자 식별 요구·공개 배포의 운영 조건.
4. 각 나라의 장소·식당·숙박 정보 범위와 최신성, 자료 부족 시 처리.
5. 사실 근거와 모델의 추천 판단 분리, 문장별 출처 연결.

방향을 확정한 뒤 조사 어댑터·저장 구조·가이드북 출력·관련 테스트를 함께 변경한다. 자료가 부족한 지역은 근거 없는 업체·가격으로 채우지 않는다.

## 공개 자료 후보의 사전 검토

| 후보 | 공식 문서에서 확인한 조건 | 적용 시 남는 일 |
|---|---|---|
| Wikidata 구조화 데이터 | 주요 엔터티 네임스페이스의 구조화 데이터는 CC0. 다른 네임스페이스의 문서나 링크된 사진까지 같은 조건으로 간주하지 않는다. [라이선스](https://www.wikidata.org/wiki/Wikidata:Licensing) | 도시·장소 식별과 좌표 등의 보조 자료 후보. 음식·숙박 정보의 충분성과 최신성을 지역별로 확인해야 한다. |
| Wikivoyage 본문 | CC BY-SA 4.0. 재배포·변형 결과에도 출처와 동일조건 배포 요건이 있다. [Copyleft 정책](https://en.wikivoyage.org/wiki/Wikivoyage:Copyleft) | 채택 시 원문·기여자·라이선스·변경 표시를 HTML과 저장본에 보존해야 한다. 사진은 별도 조건 검증 전 제외한다. |

히로시마의 [여행 안내 문서](https://en.wikivoyage.org/wiki/Hiroshima)가 존재함을 확인했다. 문서의 존재만으로 개별 업체의 현재 영업이나 모든 여행지의 자료 충분성을 검증한 것은 아니다. 실제 추천에 사용하기 전 지역별 표본과 수정 시점을 확인한다.

Wikimedia 자동 요청에는 설명적인 User-Agent와 연락 가능한 프로젝트 정보가 필요하다. [User-Agent 정책](https://foundation.wikimedia.org/wiki/Policy:User-Agent_policy). 요청에는 프로젝트 이름·저장소 URL을 넣고 maxlag를 사용한다. 공개 배포의 트래픽·캐시·분산 호출 제한 검증은 남아 있다. Wikidata는 현재 어댑터에 연결하지 않았다.
