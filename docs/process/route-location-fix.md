# 2026-11-26 · 문장형 일정의 지도 위치 조회 수정

사용자 보고: 오사카 첫날의 ‘지도에서 동선 보기’에서 일치하는 장소가 없다는 안내가 나옴.

원인: 활동 제목 전체를 검색하고 문서의 전체 제목을 문자열 비교하여 ‘후쿠시마역 고가에서 옆 골목으로’와 ‘후쿠시마역 (한신 전기철도)’를 연결하지 못함.

수정:
- 활동에서 역 이름 등 짧은 기준 장소를 추출하고 괄호 속 동명이인 구분을 제외한 이름으로 비교.
- 목적 도시의 공개 좌표와 25km 이내인 후보만 자동 연결하는 보수적인 제한. 범위 밖 장소는 수동 선택 필요. 이는 위치 정확성을 보증하는 규칙이 아님.
- 숙소·식당이 미정인 활동에는 확정 주소 대신 ‘주변 탐색 기준점’이라는 표시. 구체적인 장소명이 없는 활동은 미정으로 유지.
- 동일 위치의 일정 번호를 하나의 지도 마커에 함께 표시.
- 통신 실패와 검색 결과 없음 안내를 구분.

검증: 사용자가 제시한 문장으로 공개 위치 API 조회 성공. 지도에 연결되는 한신 후쿠시마역은 주변 탐색 기준이며 JR 역·예약 숙소·식당을 확정한 것이 아님. PC·모바일 브라우저 테스트에서 기준점 두 항목의 마커 병합과 미정 식당 안내를 확인. 단위 테스트는 괄호 이름, 원거리 동명 후보 제외, 일반적인 식사 문장의 오연결 방지를 확인.

사용자의 실제 여행 데이터는 저장소에 포함하지 않음. 기존 가이드북을 다시 생성할 필요 없이 새 화면에서 지도 조회 가능.
