화면 캡처는 자동화 테스트의 예시 데이터로 생성되었으며 실제 개인 여행·키를 포함하지 않는다. 추후 사용자 디자인 지시와 전후 비교를 별도 추가한다.

## 2026-11-23 디자인 교체 요청 · 시안 선택 전

사용자 지시 원문:

> 첫 화면뿐만 아니라 가이드북 모두 다 디자인에 큰 변화가 필요해. 일단 글씨체가 너무 기본 폰트라서 전혀 예쁘지 않아. 그리고 전체적인 색상 톤도 누리끼리한 색상에 파스텔 톤인 게 너무 맘에 안들어. 흰색과 쨍한 파란색 조합이라거나 좀 더 모던한 색상의 조합을 다양하게 적용해봐. 내가 맘에 드는 걸 선택할테니 그걸로 전체적으로 교정해주면 될 것 같아. 그리고 호버 기능이라거나 아이폰의 글래시한 느낌 등등이 적용되면 좋을 것 같아.

첫 구현은 `before/`의 네 캡처와 Git 기록에 유지한다. `public/design-preview/`에서 Pretendard 가변 글꼴, 블루·잉크/라임·바이올렛 색상 시안, 반투명 탐색 막대와 호버 반응을 비교한다. 시안은 예시 내용을 사용하며 API 호출이나 실제 여행 생성 기능은 없다. 아직 선택받은 최종 디자인이나 적용 완료 사례로 집계하지 않는다. 사용자의 선택 후 실제 앱과 HTML 출력의 전후 자료를 연결한다.

글꼴: [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard), v1.3.9. 배포 파일과 SIL Open Font License는 시안의 `fonts/`에 함께 보관한다.

## 2026-11-23 A 시안 선택과 설치 기능 요청

사용자 지시 원문:

> A 시안이 마음에 드는데, 너무 획일적이면 지루하니까 B나 C도 적절히 사용하거나 다른 시안을 적용해도 좋아. 네 창의력을 펼쳐봐 별로면 내가 지적할게. 그리고 이 사이트는 링크가 있어야만 들어갈 수 있어? 어플이나 아이콘을 만들어주면 편할 것 같은데. 그리고 목표가 정체됐는데 계속 이어서 해줘

반영: 첫 화면·입력·편집·보관함·키 설정·가이드북·HTML 출력에 흰색/파랑과 Pretendard를 적용했다. 다중 거점 여행책에는 잉크색 표지와 라임 강조를 사용한다. 탐색 막대와 진행 안내의 유리 질감, 버튼·책 표지의 호버, 키보드 초점과 동작 감소 설정을 함께 적용한다. 초기 기본 폰트·누런 배경·일관되지 않은 상호작용을 바꾼 이유는 직전 사용자 피드백에서 가져왔다. 사용자 선택은 A 중심 방향에 대한 것이며, 최종 화면의 만족도 확인과 추가 피드백은 별도다.

설치형 웹앱의 manifest·아이콘·설치 안내를 추가했다. 서비스워커는 정적 오프라인 안내만 캐시하고 개인 키·여행 응답은 캐시하지 않는다. 실제 아이폰 설치를 완료한 것으로 기록하지 않는다. 내려받는 HTML에는 글꼴과 라이선스를 포함하고 템플릿 버전을 2로 올린다.
# 2026-11-23 API 키 연결 상태 피드백

사용자 원문:
> 로그인했어 잘 돼. 근데 API 키 연결 설정하는 부분 클릭한 뒤 API 키 연결하면 연결완료와 같이 아이콘이 바뀌게 해줘. 지금은 API 키 연결해도 버튼에 변화가 없으니 된건지 확인이 안돼. 그리고 누르면 또 API 키 입력하는 창이 나와.

반영: 연결 확인 성공을 별도 상태로 관리하고 체크 아이콘·완료 문구를 표시. 완료 상태에서 다시 열면 연결 관리 화면을 제공. 입력만으로 성공 처리하지 않으며 변경·해제·새로고침 시 완료 표시를 초기화한다.
