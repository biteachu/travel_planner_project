# 제품 요구와 수정 기록

## 2026-11-18 — HTML 가이드북을 핵심 결과물로 명시

사용자 지시 발췌(제품 요구):

> 여행을 좋아하는 사람들에게 가이드북 형태(html)의 여행 계획표를 만들어주는 시스템이지
> 웹앱으로 제작하고, 거기에 각자의 API키를 입력하면 이 에이전트들이 여행 계획을 기깔나게 만들어주는거야.
> 최대한 사용자들의 여행 취향에 맞춘 맞춤형 여행 계획을 세워주는거지.

반영: 웹앱 입력·계획·편집 화면과 단일 HTML 가이드북 출력기를 구현. 초기 시각 구현은 before 폴더에 저장. 이 지시는 제품 방향에 관한 것으로 디자인 수정 3개를 충족했다고 보지 않는다.

## 초기 구현 검증

- TypeScript 검사 통과.
- 단위 테스트 8개 통과: 날짜·중복·고정 보호·미확인 비용·URL·HTML 코드 주입.
- 데스크톱/모바일 E2E 6개 통과: 예시 편집·보관·다운로드·오프라인 열람, 키 비저장, 잘못된 날짜.
- 프로덕션 빌드 통과(Webpack). 이 환경의 Turbopack 하위 프로세스 연결 오류로 Webpack을 사용한다.
- 실제 Gemini·Supabase 연결 검증은 아직 수행하지 않았다.

화면 캡처는 자동화 테스트의 예시 데이터로 생성되었으며 실제 개인 여행·키를 포함하지 않는다. 추후 사용자 디자인 지시와 전후 비교를 별도 추가한다.
