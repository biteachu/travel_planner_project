# 2026-11-25 · 읽기 쉬운 사진·동선 가이드북

## 사용자 지시

> 여행 일정을 한 번 만들어봤는데, 문제가 여럿 보여. 일단 가독성이 전반적으로 떨어져. 글자가 너무 많고. 사진이 전혀 없는 것도 여행 가이드북이라는 측면에서 마이너스 요소야. 그리고 동선이 지도로 나오도록 구글맵 등을 연동해서 보여주면 좋겠어. 그리고 결과물을 내리면서 보다보면 제일 위로 한 번에 가는 버튼이 있으면 좋겠는데 그것도 만들어줘.

> 일본 오사카와 교토를 중심으로 4박 5일 여행 일정을 만들어달라고 했어. 전체적으로 그냥 텍스트만 있는데다가 여행 전에 확인할 사항이 너무 길어서 읽고 싶지 않았어

## 수정 전 → 수정 후와 이유

| 항목 | 수정 전 | 수정 후 | 이유 |
|---|---|---|---|
| 읽는 순서 | 확인 사항과 긴 설명이 그대로 펼쳐짐 | 확인 사항은 개수만 먼저 표시하고 펼치기, 활동은 짧은 설명과 상세 펼치기 | 일정의 핵심을 먼저 읽고 필요할 때 상세를 확인하기 위해 |
| 사진 | 생성 가이드북에 여행 사진 없음 | 도시 이름이 일치하는 공개 문서의 대표사진 자동 조회, 출처·저작자·라이선스 표시 | 여행 분위기를 시각적으로 전달하기 위해 |
| 동선 | 장소별 지도 검색 링크 | 날짜별 방문 순서, 위치 지도, Google Maps 구간별 길찾기 | 하루 이동 순서를 한눈에 파악하기 위해 |
| 긴 문서 탐색 | 스크롤로 직접 위로 이동 | 고정된 ‘맨 위로’ 버튼 | 긴 가이드북의 처음으로 쉽게 돌아가기 위해 |

사진은 도시 대표 이미지이며 개별 일정 장소의 사진이라고 주장하지 않습니다. 사진·지도 보완에서 검색·교체·해제가 가능합니다. 표지 사진은 최대 세 장, HTML 내보내기에서 ‘오프라인 사진 포함 준비’를 누르면 사진을 파일 안에 담습니다. 사진 조회 실패 시 텍스트 가이드북은 계속 사용할 수 있습니다.

지도는 공개 문서에서 이름이 일치하는 장소의 좌표를 사용합니다. 지도 버튼을 누르면 위치를 조회하며 확인되지 않은 장소는 임의 좌표를 만들어 표시하지 않습니다. 점선은 방문 순서이고 도로 경로나 소요시간이 아닙니다. 실제 길찾기는 Google Maps에서 이동 수단과 장소를 확인합니다. HTML에는 배경 지도 타일을 저장하지 않고 방문 순서 그림과 온라인 링크를 넣습니다. 위치와 사진을 다음에도 유지하려면 ‘보관’을 누릅니다.

## 확인 기록

- 사용자는 오사카·교토 4박 5일 일정 생성 성공 후 가독성 문제를 보고했습니다. 계정 저장·불러오기 성공까지 확인한 것은 아닙니다.
- 실제 공개 API에서 오사카·교토 대표사진과 이용 조건, 오사카 사진의 HTML용 JPEG 압축을 확인했습니다.
- PC·모바일 테스트에서 접힌 확인 사항, 사진 표시, 지도 마커, 가로 넘침, 맨 위 이동을 확인했습니다. 지도 자동화 테스트의 장소 응답은 고정 테스트 자료입니다.
- Chrome·Edge의 31일 HTML 오프라인 열람·인쇄 테스트를 통과했습니다.
- `screenshots/2026-11-25-guidebook/`에는 PC·모바일 대표 화면 각 한 장만 남깁니다. 오사카·교토 5일 화면은 UI 검증용 테스트 일정이며 사용자의 실제 생성 결과 원본이 아닙니다. 영상은 제작하지 않았습니다.
