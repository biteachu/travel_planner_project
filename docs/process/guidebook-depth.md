# 장소별 사진과 읽을거리 보강

## 사용자 요청

“사진이 제일 위에 몇 장만” 있고 “그냥 동선만” 있다는 지적을 받았습니다. 일정별 사진, 식당·술집·이자카야의 특징과 메뉴를 비교하는 별도 탭, 관광지의 역사적 배경과 관람 포인트를 요청하셨습니다.

| 항목               | AI가 처음 준 것                       | 내가 바꾼 것                                             | 바꾼 이유                                 |
| ------------------ | ------------------------------------- | -------------------------------------------------------- | ----------------------------------------- |
| 디자인 · 정보 구성 | 일정과 설명을 한 화면에서 계속 스크롤 | 여행 일정·장소 해설·맛집·술집·여행 준비를 네 탭으로 구분 | 원하는 정보를 골라 읽도록                 |
| 디자인 · 사진 배치 | 상단 도시 대표사진 중심               | 일정과 장소 해설 카드에 해당 장소의 사진 배치            | 여행지의 모습을 동선과 함께 이해하도록    |
| 디자인 · 장소 카드 | 짧은 활동 설명                        | 소개·관람 포인트·접을 수 있는 역사 설명·사진 출처        | 가독성을 유지하며 깊이 있는 내용을 읽도록 |
| 기능 · 음식점      | 단순 식당 후보                        | 도시별 후보, 업종·특징·분위기·메뉴 설명·확인 사항        | 식당과 술집을 구체적으로 비교하도록       |
| 기능 · 기존 여행책 | 생성 당시 내용만 표시                 | 날짜·동선은 유지하는 내용 보강 기능                      | 저장된 여행도 다시 만들지 않고 개선하도록 |

## 구현과 검증

- 공개 자료를 조회하는 조사·큐레이션 지시를 강화했습니다. 장소 설명은 일정 ID와 제목에 연결하며 알 수 없는 출처 ID를 거부합니다. 이 검사는 문장별 사실을 자동으로 보증하지는 않습니다.
- 재사용 조건이 확인된 사진을 이름·위치로 검색합니다. 사진이 없는 장소에 다른 사진을 임의로 채우지 않으며 직접 교체·제거할 수 있습니다.
- 기존 JSON을 계속 열 수 있습니다. 보강 실패·취소 시 기존 일정을 유지합니다. HTML 내보내기에 사진·설명·출처를 함께 담을 수 있습니다.
- 단위 테스트 106개 통과, 1개 건너뜀. PC·모바일 장소 사진·탭·키보드 탐색·지도 관련 브라우저 테스트 6개 통과. 프로덕션 빌드 통과.
- 기존 가이드북 회귀 테스트 46개 중 최초 39개 통과 후, 탭·접힌 출처에 맞춘 테스트 갱신과 모바일 알림 클릭 방해 수정을 적용했습니다. 관련 8개 재검증을 완료했습니다. HTML 오프라인 검증 2개는 로컬 서버를 재시작한 뒤 통과했습니다. 테스트 캡처는 임시 결과 폴더에만 저장해 과거 화면 증거를 덮어쓰지 않습니다.
- 실제 저장 여행책에서 새 화면을 확인했습니다. 실제 AI 내용 보강은 ChatGPT의 새 연결 동의가 필요하여 완료하지 않았습니다. 생성 내용의 충실도와 실제 업체·메뉴는 별도 검토가 필요합니다.
- 테스트에서 사용하는 업체와 해설 문구는 테스트 자료이며 사용자 여행의 실제 추천으로 저장하지 않습니다.
