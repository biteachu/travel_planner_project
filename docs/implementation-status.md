# 구현 상태와 다음 검증

2026-11-18. 전체 목표는 진행 중이며 제출 완료가 아니다.

## 현재 확인한 것
- `video/`에 Remotion 트레일러와 과정 영상 편집 초안 코드를 작성했다. 트레일러 MP4의 실제 메타데이터는 45초·1280×720·30fps이며, 추출한 가이드북 장면과 한국어 표시를 확인했다. 영상 TypeScript 검사도 통과했다. 예시 화면·프로토타입 표기를 유지하며 실제 생성 품질이나 배포 완료를 주장하지 않는다.
- 과정 영상은 2분 30초 구성과 실제 수정 사례 세 건을 입력할 틀을 준비했다. 지시 원문·이유·커밋·전후 이미지가 아직 등록되지 않아 증거 검사는 통과하지 않는다. 제출 영상 완성으로 집계하지 않는다.
- Next.js 프로덕션 빌드 통과(Webpack).
- TypeScript 검사 통과.
- API 본문은 전체를 읽은 뒤 크기를 검사하는 대신 수신 중 UTF-8 바이트 한도(350,000)를 검사한다. 초과 길이 헤더는 읽기 전에 거절하고, 누락·축소된 헤더도 실제 수신량으로 차단한다. 청크 경계의 한글 복원, 한도 초과 시 스트림 취소, 모델 미호출·413 응답을 테스트했다. 전체 단위·DB 46건 통과 후 API 통합 사례를 추가하여 관련 8건을 재검증했다.
- 단위·로컬 DB 테스트 42개 통과: 날짜·출처 연결·고정 변경, 위험 링크·HTML 주입, 날짜별 생성 재개, API 오류 마스킹·동시 실행 잠금, 미완성 입력 초안 복원·알 수 없는 필드 제외, 활동 순서 교환·고정 보호·시간 겹침, 내보내기 선택 적용과 원본 보존, 확정 예약・활동 가능 시간 제약·응답 거절과 재개, 후보 출처·출력·예산 분리 등.
- Chrome 데스크톱/모바일 E2E 24개 통과: 예시 수동 편집·보관·HTML 다운로드·오프라인 읽기, 키 비저장·새로고침 삭제, 잘못된 날짜 입력, 입력 초안 자동 보관·복원·삭제, 체류 시간·순서 변경·고정 보호, 확정 예약 추가·충돌 거절·복원·삭제, 중단·재개, 식당·숙박 후보 비교.
- 확정 일정은 날짜·시작 시간·소요 시간·종류·이름으로 입력한다. AI의 날짜별 생성과 재생성에서 예약 누락·변경·고정 해제·중복·다른 활동과의 겹침을 거절한다. 확정 일정끼리 겹침·기간 밖 날짜·자정 초과도 입력에서 거절한다. 자유 서술 메모의 모든 조건을 구조화한 것은 아니며 실제 예약 유효성은 검증하지 않는다.
- 첫날 활동 시작 가능 시간과 마지막 날 활동 종료 시간을 현지 시간으로 입력·복원하고 가이드북에 표시한다. 모든 활동 종류에 적용하며 날짜별 생성과 재생성의 위반 응답을 거절한다. 당일 여행의 시간 역전과 가능 시간 밖의 확정 예약을 입력 단계에서 검사한다. 공항 이동·수속 여유는 사용자가 반영하며 항공편 운항을 조회하거나 자유 서술 도착 시간을 자동 해석한 결과가 아니다.
- 활동 순서 변경은 인접 활동과 시작 시간을 교환한다. 체류 시간·이동 정보는 유지하고 시간 충돌은 자동 검사로 알린다. 수동 편집 시 이전 상태의 AI 수정안을 닫는다.
- 입력 초안은 미완성 상태와 입력 단계를 브라우저에 보관하며, 저장소 실패를 안내한다. 별도 생성 체크포인트와 분리하여 새 입력이 중단된 생성 조건으로 덮어써지지 않게 한다.
- 서버 요청 단위 역할: 총괄, 조사, 날짜별 일정, 예산, 큐레이터, 검토. 하루 수정안은 적용 전 비교한다.
- 초기 생성의 검토 후에는 하루 단위 자동 수정을 최대 두 차례 수행하고 매번 재검토한다. 고정 일정·활동 가능 시간·출처를 검사하고 선택하지 않은 날짜·거점·조건을 보존한다. 수정 횟수는 체크포인트에 남기며 한도 이후에도 문제가 남으면 확인 경고로 종료한다. 해결된 코드 검사 경고는 현재 일정으로 다시 계산한다. 모의 API 전체 생성 흐름을 데스크톱·모바일에서 확인했으며 실제 모델 품질 검증은 별도다.
- 추가 질문 답변은 원래 취향과 별도 필드로 보관하여 함께 생성 요청에 전달한다. 모의 API를 사용한 데스크톱·모바일 흐름에서 보존을 확인했다.
- 조사 원문과 제공사가 반환한 문장별 출처 연결을 예산·큐레이터·검토 단계에 전달한다. 조사 목록에 없는 출처 ID를 쓴 생성·수정 응답은 거절한다. 존재하는 출처 ID만 사용한다고 문장 내용까지 사실로 입증되는 것은 아니므로 실제 근거 적합성 검증은 남아 있다.
- 날짜별 완료 결과를 브라우저 체크포인트에 보존한다. 키는 포함하지 않고, 재개 시 본인 키를 다시 입력한다.
- 중단한 요청은 응답 본문 수신 후에도 취소 여부를 검사하고 완료된 요청의 컨트롤러를 정리한다. 생성 시작의 체크포인트 검증 오류도 화면 오류 처리 범위에 포함한다. 응답을 지연시킨 모의 API로 중단 후 완료 날짜 보존·키 제외·남은 날짜만 재요청·최종 체크포인트 제거를 데스크톱/모바일에서 검증했다. 관련 정상 생성 흐름을 포함한 E2E 4건이 통과했다. 실제 제공사 작업 중단이나 과금 취소를 보장하는 검증은 아니다.
- 조사도 중복을 제거한 숙박 거점별 요청으로 분할한다. 완료한 거점의 자료를 체크포인트에 보존하며 실패한 거점부터 재개한다. 합칠 때 거점별 출처 ID와 문장 연결을 유지하고 길이 제한으로 생략한 자료는 명시한다. 여러 거점의 출처 충돌 방지와 실패 후 재개를 모의 테스트로 확인했다.
- 골격 승인 화면에서 기본 생성 요청 횟수와 재시도·도구 검색에 따른 추가 사용량 가능성을 안내한다. 실제 과금액을 계산하거나 확정하지 않는다.
- 가이드북은 단일 HTML로 내보내며 비용 미확인을 0원과 구분한다.
- 큐레이터는 식당·숙박 지역·숙소 후보를 추천 이유·비교할 점·선택 전 확인 사항·출처와 함께 구조화한다. 새 후보의 출처 누락과 알 수 없는 출처 참조를 거절한다. 가이드북과 HTML에 비교 목록을 표시하고, 숙박 제외 선택을 적용한다. 후보는 확정 예약·일정·예산 합계와 분리하며 자료 부족 시 빈 상태를 표시한다. 기존 후보 필드가 없는 저장본도 읽는다. 후보 출력과 모바일 탐색은 모의 데이터로 확인했으며 실제 업체 추천 품질은 아직 검증하지 않았다.
- 홈의 '만드는 과정 살펴보기'에서 역할별 예시 설명을 수동 이동·자동 재생·일시 정지할 수 있다. 실제 호출이 아닌 예시임을 표시하고 체험용 가이드북으로 연결한다. 데스크톱·모바일에서 진행·일시 정지·API 요청 없음·예시 열기를 검증했다.
- 잠정 잔여 예산·초과 금액을 표시하며 미확인·미입력 경비가 빠진 수치임을 알린다. 수동 환산은 원래 금액·통화·1단위당 환율·기준일·출처를 보존하고 통화별 소수 단위를 반영한다. 직접 비용을 수정하면 기존 환산 기록을 제거한다. AI가 새로 만든 환산 기록을 사용자 입력으로 표시하지 않으며, 실제 환율을 조회하지 않는다.
- 내보내기 전 소개·동행 정보, 활동 설명, 숙박 상세, 예산 포함 여부를 선택하고 동일한 출력 HTML을 미리 본다. 선택은 원본을 바꾸지 않는다. 자유 서술 속 개인정보 자동 탐지·삭제 기능은 아니며, 남는 제목·출처·다른 문장을 확인하도록 안내한다.
- Chrome 인쇄 미디어에서 접힌 날짜 본문이 펼쳐지고 목차가 숨겨짐을 데스크톱·모바일 E2E에서 확인했다. 데스크톱 PDF 파일 생성도 확인했다. 모든 브라우저의 인쇄 결과나 모든 여행 길이의 페이지 구성을 검증한 것은 아니다.
- 계정 저장은 변경된 스냅샷을 DB 트리거로 버전 테이블에 함께 기록하며, 동일 저장 반복은 버전을 중복 생성하지 않는다. 계정 삭제 UI는 여행·버전과 현재 브라우저 보관본을 삭제하도록 연결했다. 다른 기기의 로컬 사본은 자동 삭제하지 않는다.
- 같은 스키마 SQL을 로컬 PGlite에서 실행하여 두 사용자 간 읽기·수정·삭제 차단, 버전 직접 위조 차단, 동일 여행 ID의 사용자별 분리, 동반 삭제, 스키마 재적용을 검증했다. 실제 Supabase Auth·SMTP·배포 환경 검증은 아직 아니다.

## 외부 설정·검증 필요
- 실제 Gemini 키/모델 권한, Maps→Search 대체, 한국어 결과 품질. 모의 테스트를 실제 생성 성공으로 간주하지 않는다.
- Supabase 프로젝트 설정, 스키마 적용, 이메일 로그인, 두 계정 간 RLS 실증.
- Vercel 프로젝트 연결·공개 배포, 분산 요청 제한. 현재 제한은 프로세스 단위이며 배포 전체의 한도를 보장하지 않는다.
- Grounding 결과의 표시·보관·HTML 배포 조건: 공식 약관에서 Maps 데이터 내보내기·수정·저장 제한을 확인했다. 현재 조사 방식은 HTML 가이드북 요구와의 충돌을 해결하지 못했으며 공개 서비스 검증 미통과다. 검색 제안 표시도 미구현이다. 단순 출처 표기로 해결했다고 간주하지 않는다. [조사 자료 정책](source-policy.md)에 근거와 대안 검토를 기록했다.
- 개발 도구 audit: picomatch 관련 high 경고가 전이되어 5건 보고됨. 조회 당시 레지스트리 latest는 4.0.7로 취약 범위에 포함. 무리한 메이저 다운그레이드 없이 패치 버전과 의존 관계를 재확인할 것.

## 구현 보완 필요
- 자유 서술 조건의 확인·반영 범위 안내.
- 실제 조사 자료에서 숙소·식당 후보의 취향 적합성·동선·출처 내용 일치를 확인. 내보내기와 비교 화면은 구현했으나 실시간 예약·메뉴 확인은 하지 않는다.
- 실제 생성 결과에 대한 검토·자동 수정의 품질 확인.
- 예약 관리 코드를 별도 비공개 필드로 분리하고 생성 본문에 전달하지 않는 구조 보완. 긴 가이드북 인쇄의 페이지 분할과 다른 브라우저 확인.
- 실제 Supabase에서 계정 저장·버전 보존·삭제와 인증 흐름 검증. 실제 제공사 호출 중 중단과 오류 복구 확인.
- 실제 도구 응답으로 거점별 조사 품질과 검색 출처 대응을 검증.
- 실제 수정 증거를 연결한 과정 영상 렌더링과 최종 트레일러 갱신. 현재 트레일러는 무음 자막 초안이다.
- 공개 배포 URL, 별도 날짜 5일 이상 커밋, 사용자 디자인 수정 3건, 두 영상, 최종 CHECKLIST와 패들릿 제출.
