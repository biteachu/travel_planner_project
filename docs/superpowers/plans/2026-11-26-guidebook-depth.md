# 장소 중심 여행 가이드북 Implementation Plan

**Goal:** 일정마다 사진과 장소 해설을 제공하고 맛집·술집을 별도 화면에서 비교한다.
**Architecture:** 기존 Trip에 하위 호환 가능한 장소 해설·추천 상세 필드를 추가한다. 공개 자료 조사와 큐레이터를 강화하고, 기존 여행책에도 일정을 보존하는 보강 작업을 제공한다. 사진은 활동 ID/제목과 연결하고 재사용 조건이 확인된 Commons 사진만 사용한다.
**Tech Stack:** 기존 Next.js, React, Zod, Wikivoyage, Wikimedia Commons.
**Spec:** 사용자 요청: 장소별 사진, 관광지 역사·관람 포인트, 별도 맛집·술집 탭 및 특징·메뉴 설명. 기존의 창의적 구현 위임에 따라 기존 구조를 확장한다.

## Constraints
- 영상 제작 제외. 강제 푸시·기록 합치기 금지.
- 출처 없는 업체·역사·메뉴를 채우지 않는다. 조회 시점은 현재 영업 확인을 뜻하지 않는다.
- 저장된 일정·고정 예약을 보강 과정에서 변경하지 않는다.
- HTML 다운로드에도 사진 출처와 설명 유지. 숙박 정보 제외 옵션 준수.

## Tasks
- [x] Trip, agents: 장소 해설과 식당 상세 스키마, 공개 자료 기반 큐레이션 및 출처·활동 연결 검증.
- [x] 사진: 활동 연결, 자동/수동 검색, 도시 대표사진과 장소사진 구분, 다운로드 확장.
- [x] Guidebook: 일정·장소 해설·맛집 술집 탭, 사진 카드, 모바일 및 오프라인 전체 열람.
- [x] 기존 여행책 보강: 자료 재조사→큐레이션, 취소/실패/여행 전환 보호 및 저장.
- [x] 테스트: 하위 호환, 허위 출처/고아 활동 거부, 사진 연결·내보내기, 탭 키보드/모바일; 빌드.

## Review focus
- 오래된 JSON도 열리고 보강 전에는 빈 화면 대신 상태와 방법 표시.
- 수정된 활동 제목에 과거 사진·해설이 붙지 않음.
- 부분 조회 실패는 기존 사진을 지우지 않음.
- 사진 저작권·출처 유지, 잘못 연결된 사진을 제거할 수 있음.
- 상세 설명을 모두 펼쳐 가독성을 해치지 않음.
