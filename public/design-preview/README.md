# 디자인 비교 시안

`/design-preview/index.html`에서 A/B/C 색상, 제목 굵기, 유리 질감, 호버와 일정 접기를 비교한다. 실제 생성·저장 기능이 없는 시각 검토용 시안이며, 사용자의 선택 전에는 운영 화면의 디자인을 교체하지 않는다.

- A: 흰색 + 선명한 파랑, 굵은 제목.
- B: 잉크색 + 라임 표지, 흰색 정보 본문.
- C: 흰색 + 선명한 보라, 가벼운 제목, 반투명 탐색 막대.
- 키 입력이나 외부 API 호출 없음. 글꼴도 이 폴더에서 제공.
- Pretendard v1.3.9: https://github.com/orioncactus/pretendard
- 글꼴 원본 배포: https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2
- SIL Open Font License: `fonts/LICENSE.txt`.

선택된 방향은 이후 실제 앱, HTML 가이드북, 인쇄 스타일에 적용하며 그때 변경 전후 자료와 CHECKLIST를 연결한다. 시안 제작을 최종 디자인 승인이나 과제 수정 3건 완료로 기록하지 않는다.
